`skills/profile-authoring` separates ending a run from crediting it. A null may end a run, but it counts as success only when a party outside the run reproduces its coverage certificate: the searched space as data (parameter ranges, enumeration or sampling method with seeds, bound reached), one row per cell, a calibration cell with positives, and a reproducer the outside check reruns on every cell or on a sample it draws, with a fixed pass rule. A null without a certificate is recorded as stopped and unverified. Traps are written as what the held-back acceptance refuses, never as what the proxy passes. A worked example shows the pcn-power null as a certificate. A blind trial found that an in-run check accepting a documented null on its fields made that null the cheapest hack in 11 of 16 judgments (discovery-lab#1137).
