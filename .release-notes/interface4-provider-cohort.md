Adopt the published portable-transfer provider cohort. Accepted transfers require the exact request and receipt; retained start attaches through the provider's authoritative lookup and dispatches the receipt's run coordinates without allocating a replacement. Recovery binds the profile, complete workspace snapshot and accepted receipt, and never destroys the imported destination on failure. Ordinary retained starts remain unchanged. Export the existing pure `assertProfileMaterializes` helper for clients whose provider has no optional profile-validation method.

The packed-package check installs CLI Bridge, Tangle, Daytona and E2B adapters with strict peers and exercises receipt-authorized attachment and first dispatch through the public CLI Bridge adapter. This fixture makes no cloud allocations or model calls. Tangle and other adapters remain unavailable for attachment until their deployed capabilities qualify it; package checks do not replace live Braid evidence.
