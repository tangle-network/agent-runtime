**Breaking.** `runStrategyEvolution` runs on Eval's search kernel and returns a projection of its search ledger. The generation loop, its JSON checkpoint and its archive are gone.

- Every strategy is a node: the `root` strategy (default `refine`) or a module the author wrote, content-addressed by its source. The default policy is `beam({ width: 2 })` and the default allocator `asha()`; pass `policy` and `allocation` to change them. The author reads train results and its parent's source only; strategies are ranked on the private `selection` tasks; the claim runs the root and at most 3 finalists together on the sealed `test` tasks, once, with a power check and a Bonferroni decision. `report.decision` is `ship` only when that claim shipped, re-derives from the ledger, every cost is known, and the shipped finalist's test lower bound is above zero.
- The ledger at `<outDir>/<searchId>/ledger.jsonl` is the only checkpoint: the same call continues an interrupted search and returns a finished one without running anything. A module the contract lint refuses, or a reply with no module, is recorded as an invalid node with its reason.
- Cells run through Runtime's `searchExecutor` on one dedicated lane of `concurrency` slots: each `runAgentic` run is one paid call on the search's cost ledger, a finished attempt is recorded under its run id and adopted after a restart, each attempt is a trace whose root span carries `agent.branch.id`, and `workerSlots` bounds working cells across searches. A run a killed process left pending settles with an unknown cost.
- `strategyTournament(state, split, names)` projects a split's settled cells into a per-task, per-strategy table; the report carries it for train, selection and test.
- `runAgentic` shots and analyst calls now report provider-billed dollars, so `BenchmarkReport` and evolution cells carry known costs when the provider bills them. `Observation.usage.costUsd` carries an analysis call's billed dollars.
- Removed: `promotionGate`, `PromotionGateOptions`, `PromotionVerdict`, `pickChampion`, `selectChampion`, `discriminatingMeans`, `ChampionPick`, `ChampionPolicy`, `EvolutionArchiveNode`, `EvolutionBandInfo`, `EvolutionCandidate`, `EvolutionGeneration`, `ReproductionCheck`, and the config fields `tasks`, `trainN`, `holdoutN`, `holdoutOffset`, `generations`, `populationSize`, `baselines`, `objective`, `scoreTolerance`, `champion`, `championEpsilon`, `minPairedTasks`, `band`, `lossesDetail`, `reproducerCheck`, `checkpoint`, `onPhase` and `onTask`.
- Migration: pass `train`, `selection` and `test` task arrays, a `claim` with `minimumEffect`, and an `executionRef`; pass the old best baseline as `root` and the old population size as `beam({ width })`. Read `report.claim` and `report.decision` instead of `report.verdict`, and `report.strategies` instead of `report.archive`. To compare two strategies without a search, run `runBenchmark` and Eval's `decidePairedPromotion` or `heldoutSignificance` on its per-task cells.
