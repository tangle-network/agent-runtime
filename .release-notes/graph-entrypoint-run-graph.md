type: minor
---
Run agent graphs durably and as subtasks. `superviseGraphPursuit(graph, { pursuitId, runDir, ... })` on `/durable` owns a run directory for a `runGraph` run the way `supervisePursuit` owns one for `supervise()`: `supervise.lock` for the call, `observer.jsonl`, `result.json` at settle (the graph's supervised result), `failure.json` on a throw, refusal of a settled directory, and resume from the spawn journal in a new process. A new coordination verb, `run_graph`, lets a manager whose profile grants `agent_runtime_coordination_run_graph` start an `AgentGraph` (as data, or a stored graph by `graphDigest` from `SuperviseOptions.graphRegistry`) as ONE subtask: the graph's root node runs as a nested manager inside one reservation from the caller's conserved pool, every node runs its pinned profile plus its edge directive, and the subtask settles with `{ deliverable, edges }`. Its edge events land in the run journal with `graph` naming the graph's root node. `spawn_worker` refuses a profile carrying `metadata.agentRuntimeGraph`, which only `run_graph` writes, and the provider-visible profile drops it.
