Breaking: `searchMethod` takes `lanes` in place of `concurrency` and `cellUsd`. A lane is where cells run and under which cost rule: `sharedBoxLane` (workers packed into shared Sandbox boxes, capacity `boxes × workersPerBox`, estimate), `dedicatedLane` (one environment a cell, estimate), `subscriptionLane` (one seat a cell; the seat charges no dollar and reports no tokens) and `routerLane` (priced calls). A hard lane (router, subscription) refuses a paid call, the agent's or a judge's, that declares no priced maximum or would take the cell past `cellUsd`, so the kernel's hard reservation holds. Migrate `searchMethod({ concurrency: 4, cellUsd: 0.05 })` to `searchMethod({ lanes: [dedicatedLane({ capacity: 4, cellUsd: 0.05 })] })`, or to `routerLane` when every paid call declares a maximum. `improve()` with a search also takes `workerSlots` (one bound on working cells across concurrent searches) and `budgetPool` (fleet dollars: a hard-lane cell holds its `cellUsd` before it starts and waits for refunds). An agent that throws `SearchEnvironmentFault`, or fails on a transient platform error, settles `errored` and retryable, and the kernel runs a fresh attempt; it was final before. Every finished attempt is recorded under its run id before it settles, so a restarted search adopts it instead of running it twice; `ctx.search.runId` is that id, stable across restarts, for keying remote work. Fixed: a search killed during a paid call could not resume, because the call stayed pending in its cost ledger and the ledger refused every later paid call ("unresolved call(s) must be reconciled"); every resumed cell then failed. A reopened search now settles its interrupted calls first, from the provider through the lane's `recoverReceipt(call)` when it has one, else with an unknown cost, and an attempt's cost is every call tagged with its run id, so spend a killed process made for an attempt is counted when the attempt settles. Each attempt is one trace (default `<search dir>/spans.otlp.jsonl`) whose root span carries `agent.branch.id` = the node id, and the cell's `traceRef` holds the spans the exporter wrote and dropped.
