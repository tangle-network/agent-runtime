A retained turn whose exact result agent-provider-tangle refuses with `TangleCredentialCapacityError` (`provider_quota_exhausted`, 429, the Sandbox sidecar's `rate_limit_event rejected`) now commits as a failed turn coded `provider_quota_exhausted`, and a harness turn with that code is a subscription usage limit. The seat chain ends that seat's segment with `usage-limit`, selects the next seat or stage, and pauses to the chain's reset when none has room; a manager without seats pauses as for any capacity refusal. The refusal used to read as an execution needing reconciliation and was retried as transient about every 32 s: on Discovery run magnetar-rust-sandbox-20261102a children retried rejected Claude seats 1,360 times. A seat-paused manager now writes one `seat-paused` row and one `paused` event per distinct reset, never rechecks before the reset, and ends its wait when its scope aborts; one pause on that run was written 2,382 times. The unused, never-exported OpenAI tools projection of the delegation MCP tools is removed.
