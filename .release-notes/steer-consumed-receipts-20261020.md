A steer or answer now ends in `consumed` or `failed`, never in `delivered`. `Inbox.drain()` is replaced by `Inbox.take()`, which returns `{ messages, commit(attemptId, messageId), release() }`: each taken message carries its `id` and stays in the inbox until a commit runs after the provider accepts the turn, and `release()` returns uncommitted messages to the head of the queue. A turn that fails before the commit folds the same messages into the next prompt; a message released by `STEER_MAX_FAILED_TURNS` (3) turns is removed and its sender receives `failed`. A queued authority message still unread after `STEER_PROMOTION_MS` (15 minutes) interrupts the live turn. `EventAcknowledgement.by` gains `consumed` (with `receiptId` and `attemptId`) in `coordination-log.jsonl`. A message never consumed reaches the sender's next wake as a failed `tool-outcome`. `WorkerSteerAcknowledgement.effect` gains `consumed` and `failed`, and `CoordinationTools.steerWorker` accepts `onConsumption`. A custom executor whose inbox never reports consumption now ends each steer it received as `failed` at run end, where it previously stayed `delivered`.
