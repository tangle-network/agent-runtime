A keyed provider worker whose turn ends over its budget now keeps its environment: it still settles `done` with its result and `budgetViolation`, and `spawn_worker` with the same key and a `budget` starts a new worker that continues the same environment and harness session where it stopped (`resumed: "continued"`, `priorWorkerId`; the journal's `spawned` record carries `successorOf` and `continues: { ofWorker, environmentId }`). Without a `budget` the key still returns its committed result. The held environment is released by `cancel_worker` on the stopped worker, at the scope's join barrier, or after `budgetStopHoldMs` (supervise option, default 600,000 ms; `0` keeps none), whichever comes first; each release journals an `environment-teardown` with `heldRelease: 'cancel-worker' | 'scope-join' | 'hold-ceiling'`. A settled keyed worker with a `budgetStop` also carries `budgetStopNext`, which says how to continue or release it.
