Two kernel output unions gained members, a named output compatibility break. `DriverAttemptStop` now includes `quota-unavailable`: a capacity refusal whose reset falls after the run's deadline, so no wait can serve it. `SpawnEvent` now includes `workspace-checkpoint-refused` (the provider answered a checkpoint request without a checkpoint; the previous one stays the restore point), and `seat-paused` carries an optional `detail`. Exhaustive switches and maps over either union must handle the new members. Versions 3.0.44, 3.0.45 and 3.0.46 were tagged but never published, because publication refused this break as a patch; their fixes ship here: the spawn pre-flight judges the profile the provider receives, a failed coordination renewal retries, worker admission decides at spawn, and a usage-limit seat switch never ends a run.
