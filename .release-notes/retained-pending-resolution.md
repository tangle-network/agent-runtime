A supervised manager no longer ends its run on a turn left pending. A capacity refusal before dispatch, such as agent-provider-tangle's `TangleCredentialCapacityError` when no subscription account has room, is now refused before it ran and pauses the driver; it used to be named "requires reconciliation before replacement" and retried until the barren bound settled the run `driver-failed`, as Discovery run terraform-dc-tokens-20261006d did after 20 identical refusals. A turn the provider answered but cannot resolve, twice the same way or once when it would end the run, is abandoned: Runtime stops it at the provider, journals the new `execution-abandoned` kind with the outcome it confirmed (`stopped` or `uncertain`), and the driver continues in a new invocation, while the journal refuses any later admission or result of the abandoned turn. `DriverRetryRun.resolvePending` is the hook, and `DriverAttemptRecord.abandoned` marks the attempt. Time paused for capacity no longer counts toward `driverRetry.transientOutageMs`.
