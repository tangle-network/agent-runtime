Flow graphs stop at human gates. `AgentGraph.gates` (also on `GraphTopology`) declares `{ id, question, choices }` vertices that are not agents: a `routes` edge into a gate awaits the new `RunGraphOptions.decideGate({ gate, visit, question, choices, evidence })`, and one edge per choice leaves it with `when: { pointer: '/choice', equals: <choice> }`. `{ kind: 'choose', choice, by }` routes on that edge, and a `finish` leaving the gate outputs `{ [gate]: { choice, by } }`; `{ kind: 'stop', reason, by }` ends the run with no winner `'stopped'` and `GraphResult.stopped.edge` `gate:<id>`. Each decision is one `routes` ledger row `gate:<id>` with `EdgeTraversal.gate: { by, choice | stop }` and its journal twin; a decision the run journal already holds is replayed instead of asking again. The wait counts against the run's deadline. `decideGate` is required when a graph declares gates, and gates are refused inside a maps item's graph or a `run_graph` subtask. New exported types: `GateRequest`, `GateDecision`, `GraphGate`.
