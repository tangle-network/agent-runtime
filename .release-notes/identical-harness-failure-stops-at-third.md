A nested manager whose harness turns end failed with the same error and gain nothing now stops with `repeated-failure` at the third such turn, with no 5-minute window, and settles `down` naming the error, so its parent's next wake carries it within seconds of the third failure. Failures compare by text and code with ids and timestamps blanked; a failure whose text or code changes, or an attempt that made progress, starts the count again. On Discovery run us-legal-exploits-20261103b, manager s1 retried one refused turn for 2 hours over 71 attempts.
