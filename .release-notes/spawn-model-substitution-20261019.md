A spawn whose authorization runs the child on another harness, provider or model than its parent authored is no longer silent. The `spawned` journal record, `Handle`, `NodeSnapshot` and the settled worker carry `modelSubstitution: { requested, ran }`, and `spawn_worker`, `observe_agent` and the settlement a manager reads add a `modelWarning` naming the route that ran. magnetar-rust-20261017c's root reported a cross-family claude-opus referee that authorization had run on GLM-5.3.
