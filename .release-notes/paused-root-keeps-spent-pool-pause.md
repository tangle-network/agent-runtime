A root opted into `driverRetry.pauseRootStops` pauses again when its pool is spent while workers run, instead of holding inside the wait, so a steer ends the pause and the turn the returned budget buys reads it. Roots without the opt-in still hold for their running workers. Release admission now compares an interface's call signature part by part, so an optional argument member added to a callable type such as `DriveHarness` asks for a patch, not a major.
