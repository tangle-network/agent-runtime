After the repository's frozen install, run this command through the maintained gate on an admitted Linux x64 host:

```sh

```

The command supplies both `RUNTIME_BRIDGE_PACKAGE_ENTRY` and `RUNTIME_BRIDGE_NATIVE_CLAUDE_BIN`, runs the complete integration file in the current checkout, and refuses an empty, failed, skipped or pending result. It removes its temporary input installation and JSON report when finished. No logged-in subscription, model API credential, manually installed CLI or fabricated native status is required. A missing host capability is a failure; the command does not retry with weaker confinement.
